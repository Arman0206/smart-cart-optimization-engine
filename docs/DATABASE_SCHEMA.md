# Database Schema — Smart Cart Optimization Engine

Database: MongoDB Atlas (shared cluster, database name: `smartcart`)

This document describes all collections used across the platform. Collections owned by `core-service` are already implemented and live. Collections owned by `recommendation-service` and `ai-analytics-service` are proposed schemas — Student 3 and Student 4 should confirm/adjust field names as needed, then update this doc.

---

## Owned by core-service (Student 2) — LIVE

### Products Collection
Model file: `core-service/src/modules/products/product.model.js`

| Field | Type | Notes |
|---|---|---|
| `_id` | ObjectId | Auto-generated by MongoDB |
| `productName` | String | Required |
| `category` | String | Required |
| `brand` | String | Optional |
| `price` | Number | Required |
| `rating` | Number | Default: 0 |
| `createdAt` | Date | Default: now |

Example document:
```json
{
  "_id": "66f8a1b2c3d4e5f678901234",
  "productName": "Laptop",
  "category": "Electronics",
  "brand": "Dell",
  "price": 60000,
  "rating": 4.5,
  "createdAt": "2026-07-07T12:00:00.000Z"
}
```

### Cart Collection
Model file: `core-service/src/modules/cart/cart.model.js`

| Field | Type | Notes |
|---|---|---|
| `_id` | ObjectId | Auto-generated |
| `userId` | String | Required |
| `productId` | ObjectId | Required, references `Products._id` |
| `quantity` | Number | Default: 1 |
| `createdAt` | Date | Default: now |

Example document:
```json
{
  "_id": "66f8b2c3d4e5f6789012345",
  "userId": "user123",
  "productId": "66f8a1b2c3d4e5f678901234",
  "quantity": 2,
  "createdAt": "2026-07-07T12:05:00.000Z"
}
```

**Note:** when fetched via `GET /cart?userId=`, `productId` is automatically populated with the full product document (see `docs/API_CONTRACTS.md`).

## Owned by recommendation-service ( Manas) — PROPOSED

### Product Relationships Collection
Suggested fields, per the project doc:

| Field | Type | Notes |
|---|---|---|
| `_id` | ObjectId | Auto-generated |
| `productId` | ObjectId | References `Products._id` — the "source" product |
| `relatedProductId` | ObjectId | References `Products._id` — the recommended product |
| `relationshipScore` | Number | 0–1 or 0–100 scale, your choice — document whichever you pick |

Example:
```json
{
  "productId": "66f8a1b2c3d4e5f678901234",
  "relatedProductId": "<Wireless Mouse _id>",
  "relationshipScore": 0.9
}
```

Seed examples to start with (using the test products already in the shared DB):
- Laptop → Wireless Mouse
- Laptop → Mechanical Keyboard
- Laptop → Laptop Bag

### Recommendation History Collection

| Field | Type | Notes |
|---|---|---|
| `_id` | ObjectId | Auto-generated |
| `cartId` | ObjectId | References the cart session/user |
| `recommendedProductId` | ObjectId | References `Products._id` |
| `recommendationScore` | Number | Final computed score (40/30/20/10 formula) |
| `accepted` | Boolean | Whether the user added the recommended item |
| `createdAt` | Date | Default: now |

**Note for Student 3:** to get product details for scoring, call `core-service`:
- `GET http://localhost:5001/products` (all products, for popularity/rating/price comparison)
- `GET http://localhost:5001/cart?userId=<userId>` (current cart contents, already populated with product info)

## Conventions for the whole team
- All IDs are MongoDB `ObjectId` — always validate format before querying (invalid ObjectId strings will throw errors, not return `null`).
- All collections should include a `createdAt` field for traceability.
- Update this file whenever you add or change a schema — keep it in sync with your actual `*.model.js` files.
